# **App Name**: Chore Champ

## Core Features:

- Task Creation: Simple task creation with name, description, and due date.
- Task Completion: Check-off mechanism to mark tasks as completed.
- Progress Tracking: Visual progress tracking to show completed vs. remaining tasks.
- Avatar Customization: Customizable avatar that kids can personalize.
- Reward Unlocks: Unlockable rewards (badges) for completing tasks.
- AI Task Suggestions: Suggesting tasks based on common chores that kids may be expected to complete using an LLM tool.

## Style Guidelines:

- Primary color: Vibrant blue (#4285F4) to convey a sense of trust and fun. 
- Background color: Light blue (#E3F2FD) creates a playful but clean background without stealing focus.
- Accent color: Sunny yellow (#FFEB3B) for interactive elements and highlights, adds energy and excitement.
- Body and headline font: 'PT Sans' (sans-serif) for readability and a modern look.
- Use cheerful, cartoon-style icons to represent tasks and rewards.
- A clear, playful, and spacious layout suitable for young users.
- Use simple, fun animations for task completion and reward unlocks.
